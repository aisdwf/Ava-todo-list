# FlowTask

FlowTask 是一款专为高效思考者打造的现代桌面待办事项与灵感快速捕捉应用。

---

### 我们做了什么

FlowTask 围绕“**捕捉灵感零负担，专注管理不分心**”的核心体验进行构建：
1. **轻量双视窗体系**：提供了一个常驻后台、毫秒级呼出的“快速捕捉胶囊小窗”，以及一个承载全貌待办规划的“沉浸式主工作台”。
2. **本地优先与即时持久化**：所有的任务增删改查均在本地极速完成，采用嵌入式轻量数据库实现秒级响应与防丢失保障。
3. **跨视窗弱引用联动**：利用解耦的消息机制，无论在任何时刻从小窗记录一条灵感，主界面都能无缝且零卡顿地完成数据流转与视图更新。

---

### 为什么这么做

- **告别沉重的冷启动**：多数任务管理软件功能繁复，当一个突发待办产生时，用户往往因为打开软件需要等待几秒而遗忘或打断心流。FlowTask 通过随时唤醒的极简悬浮小窗，让记下一件事就像在控制台敲一行命令一样自然。
- **数据安全与高可靠性**：我们放弃了脆弱的单文本序列化方案，选用经过时间检验的嵌入式数据库引擎，既具备文本文件的轻巧无侵入，又天然保证多窗口并发读写时的 ACID 事务安全性。
- **跨平台一致的高级质感**：首发以 Windows 11 Fluent 2 设计风格为基准（亚克力/云母材质、柔和卡片边框高亮、优雅圆角与清晰的快捷键引导），同时保障 macOS 平台的原生运行与顺滑调试。

---

### 架构设计思路

- **整洁架构（Clean Architecture）与领域驱动**：
  - **`FlowTask.Core`**：只关注业务本质，定义待办实体、优先级状态以及跨组件消息契约，保持纯粹，不依赖任何第三方 UI 或平台接口。
  - **`FlowTask.Infrastructure`**：负责技术细节的落地，封装 SQLite 数据库访问通道与自建目录初始化。
  - **`FlowTask.Desktop`**：基于 Avalonia 11 构建跨平台展示层，严格采用 MVVM 响应式模式，通过弱引用消息总线解耦跨窗口生命周期，杜绝传统桌面应用常见的窗口句柄强引用与内存泄露。
  - **`FlowTask.Tests`**：内建自动化单元测试，确保底层持久化引擎在每一次演进中始终坚固稳定。
