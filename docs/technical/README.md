# 技术资料（与功能开发进度无关）

本目录用于存放**与具体功能开发进度无关**的技术性资料：架构调研、
第三方框架/开源项目源码走查、技术选型对比的原始调研记录等。

## 与 `analysis/` 的区别

- `docs/analysis/`：调研结论**归档**，服务于某次具体决策，
  通常在决策完成后不再更新（快照性质）。
- `docs/technical/`：调研的**原始材料**本身，可能被后续多次引用、
  也可能随技术演进被追加更新，不与任何单一 SPEC 或决策绑定。
- 若调研结论被提炼为强制规则，规则写入 `docs/rules/`（规范化表述，
  不搬运原文），原始调研材料留在本目录供追溯依据与案例细节查阅。

## 与 `refenence/` 的区别

- `docs/refenence/`：外部依赖协议、平台 SDK 参考手册、编码规范参考——
  面向「如何使用某个既定工具/规范」。
- `docs/technical/`：面向「调研阶段产出的技术性材料」——
  面向「有哪些可参考的方案/案例」，本身不是规范，只是依据。
