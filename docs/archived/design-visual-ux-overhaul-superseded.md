## 1. 现状痛点复盘
- **主窗口生硬简陋**: 采用生硬的深黑块（#1E1E22）、简陋的圆角与单薄线条，缺乏现代桌面端精致层次（层次感、投影、微妙边框、字体层级）。
- **随手记小窗过于突兀**: 缺乏 Raycast / Things 3 风格的灵动毛玻璃设计，无边框小窗缺少现代圆角、精致拖拽条与清晰快捷键标签。
- **功能职责边界模糊**: 
  - 主窗口既要做清单又要快速输入，导致职责重合；
  - 随手记小窗仅有单文本行，缺少快捷标签、优先级选择和快速关闭动效；
  - 缺少真正的抽屉式/侧边详情管理。

## 2. 视觉规范升级方案 (Design Tokens)

### 2.1 配色与透明材质
- **背景材质**:
  - 主窗口: 深色灰阶层级 `#141416` (底色) -> `#1B1B1E` (卡片/侧边) -> `#242429` (悬浮卡片)
  - 随手记小窗: `AcrylicBlur` 半透明毛玻璃 (`#1E1E24EE`) + 微妙边框 `#383842`
- **品牌强调色 (Accent)**:
  - 主色: 灵动天青蓝 `#3B82F6` (聚焦、按钮强调)
  - 优先级高 (High): 珊瑚红 `#EF4444` / 柔和微底 `#3B1C1C`
  - 优先级中 (Medium): 暖琥珀 `#F59E0B` / 柔和微底 `#332514`
  - 优先级低 (Low): 鼠尾草绿 `#10B981` / 柔和微底 `#162C24`
- **文字层级**:
  - 主标题/主要信息: `#F3F4F6` (高对比，清晰有力)
  - 次级辅助信息: `#9CA3AF`
  - 快捷键 Badge / 弱标签: `#6B7280`，背景 `#2B2D35`

### 2.2 圆角与间距规范
- 窗口圆角: `14px`（无边框亚克力窗口）；卡片圆角: `10px`；按钮/徽标圆角: `6px`。

## 3. 功能边界清晰拆分

| 视窗维度 | 定位与核心职责 | 交互特色 |
| :--- | :--- | :--- |
| **主工作台 (MainWindow)** | **任务全生命周期管理中心**<br>• 分类视图（今日待办、全部待办、已完成归档）<br>• 任务精细编辑（标题、详细备注、优先级徽标、时间）<br>• 批量整理与删除 | 优雅 SplitView 左侧导航栏；清晰卡片流（悬浮投影与状态切换动效）；支持双击查看备注 |
| **随手记小窗 (QuickCaptureWindow)** | **闪电捕捉灵感与即刻待办**<br>• 极速输入（1秒内唤起并落焦）<br>• 快捷键辅助（Enter 提交，Shift+Enter 连续记录，Esc 关闭）<br>• 语音输入指引（快捷键一览） | 悬浮置顶 Mini 窗（类似 Raycast/Spotlight）；无多余干扰元素；优雅淡入与快捷键 Badge 指引 |

## 4. 架构与实施落脚点
- 提取统一资源字典（颜色、笔刷、常用样式）。
- 升级 `MainWindow` 为精致 Fluent 布局（卡片式任务列表、优先级色条、空状态插画/提示、快速勾选动效）。
- 重构 `QuickCaptureWindow` 为现代毛玻璃胶囊浮窗。
