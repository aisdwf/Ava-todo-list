## 1. 灵感参考解析 (来自 res/fc3a588b-f4c4-43dd-a4c3-a68ada115472.png)
通过分析参考设计图，其具备极强的视觉冲击力与现代“大开大合”排版美感：
- **Typography as Interface (文字即界面)**：
  - 核心焦点不是密密麻麻的小格子，而是大字号（Large Bold Display）、强节奏感的标题排版；
  - 弱化琐碎的表单分割线，利用间距与明暗对比形成天然视线流（Leading Lines）；
- **极简深邃与高级灰度控制**：
  - 背景并非刺眼的纯黑，而是沉稳内敛的高级深炭灰（`#202022` / `#28282C`）；
  - 辅助文字采用低纯度但高识别度的中灰（`#8A8A93`），重要标题直接使用近纯白高光（`#F4F4F6`）；
- **呼吸感强烈的条目流 (Spacious Rhythm)**：
  - 每条项目拥有充裕的上下留白（Vertical Padding 18-24px）；
  - 序号/副标签采用精致的小字号（Micro-label）悬于标题上方或左侧，主副分明。
